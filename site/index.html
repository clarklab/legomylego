Buildable models made only of real LEGO parts, and checked by computer before anyone builds them: every part is a real LEGO element, every connection is found, nothing collides, every step can be built, and the mechanisms really work.

Checked by computer

Five things we check, every time

Each model is tested part by part by brickkit, the engine that designs it. If a check fails, the model is not done.

Real elements

Every part exists as a real LEGO element, in that colour.

Every connection

Studs, pins and axles are found joint by joint. No floating parts.

No collisions

No two parts try to fill the same space.

Every step buildable

Each part slides into place, in order, without hitting anything.

Working mechanisms

Moving parts are swept through their full range. Gears mesh.

How it works

From code to bricks

1

Designed brick by brick

Each model is placed part by part in brickkit, using real LEGO part geometry and colours.

2

Checked by computer

Connections, collisions, build order, balance and moving parts are all simulated before release.

3

Built by you

Follow the steps, then order the exact parts with a BrickLink wanted list or LEGO Pick a Brick.
