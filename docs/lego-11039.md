# LEGO 11039 as four standalone Quick Bricks models

Source: [LEGO Creative Food Friends 11039](https://www.lego.com/en-us/service/building-instructions/11039),
[official instructions 6555451](https://www.lego.com/cdn/product-assets/product.bi.core.pdf/6555451.pdf).
The independently parsed set inventory is in `references/lego_11039/`. LEGO's PDF itself is
not kept in the repo: download it to `references/lego_11039/6555451.pdf` to run the set
inventory audit (its SHA-256 is checked; the tests that need it skip without it).

| Model | Folder | Pieces | LEGO steps | Printed pages | Expanded repo steps |
|---|---|---:|---:|---|---:|
| Birthday Cake | `models/birthday_cake` | 20 | 11 | 6-11 | 12 |
| Watermelon Ice Lolly | `models/watermelon_ice_lolly` | 23 | 11 | 14-19 | 13 |
| Avocado | `models/avocado` | 23 | 15 | 22-31 | 17 |
| Taco | `models/taco` | 23 | 12 | 34-41 | 12 |

The 49 numbered source steps become 54 repo instruction entries because the candle,
seed blocks, stick and cheek callouts are real submodels. Repeated seed submodels are
reused without dropping their physical pieces. Every model is a separate build with its
own design, palette, Quick Bricks settings, source ledger, MPD, parts exports and checks.
Standalone viewer bundles are in each model's `out/viewer/models/SLUG/`, containing
`model.glb`, `model.json`, parsed assembly steps and purchasing files.
There is no shared four-model assembly.

The set contains 150 pieces in 67 element/color entries. Its four primary builds use 89
pieces. The other 61 are for alternate faces, rebuilds and free building; they are explicitly
recorded as remaining in `references/lego_11039/set_inventory.json`, not silently discarded
or added to standalone BOMs. Source pages 12-13, 20-21, 32-33 and 42-45 are alternate
builds/inspiration, not extra numbered steps for these four models.

`reference/inventory.json` in each model is transcribed independently from the source
callouts. It includes the source page, step, exact LEGO element ID, LDraw part, color and
quantity. Exact printed eyes and smiles are used. The cake's 76959 slope is vendored from
upstream LDraw's unofficial library, with its license, source URLs and SHA-256 checksums
in `brickkit/data/ldraw_sources.json`. MPD export includes its subpart dependency.

Run all eight normal checks and regenerate purchasing files:

```sh
for model in birthday_cake watermelon_ice_lolly avocado taco; do
  .venv/bin/python -m brickkit all "$model"
done
.venv/bin/python tools/audit_lego_11039.py --exports --quick --viewer
.venv/bin/python -m pytest -q tests/test_lego_11039.py tests/test_supplemental_parts.py
```

The audit checks independent source element lists against each model step, including
callout expansions, complete geometry dependencies, CSV/XML/Pick a Brick exports, MPD
round trips and step markers, and the Quick planner's final placement without rendering. The cake and
lolly retain a catalog rarity warning for their exact white/coral smile bricks. All physical
checks pass; no checks, collisions or attachments have been waived.

The models are prepared for the repo's existing tools. Validation uses the source ledgers,
geometry, connections, exports and planned steps. No video or booklet rendering is required.

Validation completed: 290 tests passed with `pytest -q --ignore=tests/test_render.py`.
The one Blender still-render smoke test was excluded to keep this task to parsing,
documentation and model checks. The final source/export/viewer audit is saved in
`references/lego_11039/audit.jsonl`.
