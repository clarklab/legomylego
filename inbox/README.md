# Inbox

Drop new models here: one folder per model, named for the model, with whatever you have.

```
inbox/
  owl/            instructions.pdf, parts.png
  frog/           frog.io
  tiny_robot/     photo.jpg
```

- Any file type is fine: PDFs, BrickLink Studio `.io` files, LDraw files, pictures,
  screenshots, a text file with a link or a note about where it came from.
- A lone file dropped straight into `inbox/` works too; whoever takes it in will give it a
  folder.
- **Nothing in here is committed.** The repo is public and git ignores everything in this
  folder but this page, so it is safe to drop paid or official instructions here.

`brickkit status` lists what is waiting. Taking a model in is stage 1 of
[docs/new-model.md](../docs/new-model.md): the agent scaffolds `models/NAME/`, copies the
pictures it worked from into `models/NAME/reference/`, and writes up the parts and steps in
`NOTES.md`. The originals stay here.
